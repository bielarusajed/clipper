Clipper uses FFmpeg 8.0.1, licensed under LGPL 2.1 or later.
FFmpeg is built without GPL, nonfree, or version3 components.
Clipper modifies libavformat/tls.h as of 2026-11-07 to enable peer certificate
verification by default. The dated patch is included in patches/ in the matching
Clipper source archive and beside the dependency sources. HTTPS uses macOS
SecureTransport and the system trust store.
https://ffmpeg.org/
The matching FFmpeg source archive and configure script are included in the
distribution's Sources folder. See FFmpeg-LGPL.txt for the license.

dav1d 1.5.4, copyright VideoLAN and dav1d authors, BSD 2-Clause license.
https://code.videolan.org/videolan/dav1d

zimg 3.0.6, copyright sekrit-twc, WTFPL version 2.
https://github.com/sekrit-twc/zimg

These libraries are dynamically linked. The build scripts and corresponding
source archives are distributed alongside the app. Modified library builds may
be substituted; the modified app must then be signed again for local use.

URL imports download yt-dlp and Deno on demand from official GitHub releases.
These tools are stored outside the app and updated independently of Clipper.
