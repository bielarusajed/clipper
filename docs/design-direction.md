# Preferred UI direction

The user selected concept C, **Recipe & Loupe**, from the first prototype round as the best direction. This is the baseline for further UI work.

Preserve its compact Mac title bar, translucent left settings sidebar, grouped clip/framing/video/audio controls, pinned export actions, large comparison viewer, and overview plus detailed filmstrip timeline. Opening a file belongs in the empty state; closing the current file returns there.

The next round explores two stronger refinements of C, one by Codex and one by Claude. Refine materials, hierarchy, spacing, and precision controls within the same design. Do not restart the layout exploration or apply a redesign to the native app before the user reviews these refinements.

The original studies are preserved on `prototype/ui-studies` at `eaa1ee3`. Round-two studies will be preserved on `prototype/c-refinements`. These are visual prototypes; the functional app on `main` is unchanged.
